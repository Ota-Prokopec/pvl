# Publish `@pvl/schema` and `@pvl/schema-compiler` as dual ESM+CJS

Both packages build with [tsup](https://tsup.egoist.dev) and publish both an ESM and a CJS output, even though `AGENTS.md`'s Core Rules commit this monorepo's own source to ESM. That rule governs how code is *authored* in this repo; these two packages are published deliverables consumed by arbitrary downstream apps, some of which are still on CJS — restricting them to ESM-only would exclude those consumers, and a publish-format change later is a breaking release. tsup builds the dual output from the same ESM TypeScript source, so this doesn't change how the packages are written, only what `tsup.config.ts` emits.
