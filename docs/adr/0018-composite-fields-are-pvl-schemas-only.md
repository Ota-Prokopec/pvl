# Composite fields are `@pvl/schema` Schemas only

A field of `pvl.object`, an element of `pvl.array` and a member of `pvl.union` must be a `@pvl/schema` Schema: at runtime an instance of the `Schema` base class, including one whose chain a Transform or `pvl.compile()` ended ([ADR-0016](./0016-transform-and-compile-end-the-modifier-chain.md), [ADR-0020](./0020-schema-class-owns-the-pipeline-and-compile-returns-a-plain-schema.md)). A composite calls each child's `_validate(value, [...path, key])` directly, so the child reports its `Issue`s at their full path from the outermost Schema itself: there is no Standard Schema dispatch, no `Issue` path re-prefixing and no `PvlStandardSchema` type.

This reverses two earlier versions of this record. The first accepted any Standard Schema as a child; the second narrowed that to any Standard Schema `@pvl/schema` produced, interpreted or compiled, dispatching on `~standard.validate` and re-prefixing paths for anything that was not an instance of the base class. Both existed only because a Compiled Schema was then a plain Standard Schema object outside the class hierarchy. Once a Compiled Schema became a subclass instance of the base class (ADR-0016, now `Schema` per ADR-0020), a nested compiled child is a Schema like any other, and the dispatch, the path re-prefixing and the vendor-literal type that guarded them have nothing left to do.

Schemas from other libraries (Zod, Valibot, …) stay excluded, even though they implement the same protocol. A composite relies on two properties a foreign schema guarantees neither of: a synchronous result, which `@pvl/schema`'s synchronous-only `validate()` needs, and coded `Issue`s, which a parent's `Result` promises consumers ([ADR-0011](./0011-result-failure-branch-carries-pvl-issue.md)). The exclusion is enforced at the type level: a child is typed as `Schema`, which requires the internal `_validate` member a foreign Standard Schema does not have. There is no runtime check in the factories; a caller who casts past the type is on their own.
