# Emitter methods return source text only

**Every Emitter method whose name starts with `emit` or `_emit`, and every method mirroring a Schema method, returns source text: a string, or a list of strings for a list of parts. The Frame takes only source text and assembles it.** This supersedes [ADR-0023](./0023-compiled-schemas-inline-nested-schemas-and-mirror-schema-methods.md)'s "Each method returns a check (the condition it fails under and its Issue) or JavaScript source text", and the hooks [ADR-0027](./0027-the-frame-composes-emitters-emit-and-the-root-frame-writes-the-compiled-schema.md) named.

A pre-modifier's method returns its short-circuit condition as an expression (`.optional()` writes `field0 === undefined`), and the Frame joins a Schema's conditions with `||`. A post-modifier's method returns a statement: a Constraint writes its check with `emitCheck({ failsWhen, issue })`, and `.strict()` and `.passthrough()` write their loops. `_emitBaseCheck` returns the base check as one statement too, written the way a Constraint's is. The Frame puts the rest of a Schema's checks in the base check's `else`, at the root as nested, so they read the value as the type it checked. At the root, `return { issues };` follows the `else`, which always returns, so only a failed base check reaches it. This replaces the root's returning base check, `if (…) { issues.push(…); return { issues }; }`, which the Frame could only write from the condition and the Issue held apart. The emitted root changes: its checks sit one level deeper.

Branded string types in `src/types.ts` keep the kinds of text apart at compile time, now that object shapes no longer do: `EmittedCheck`, `EmittedShortCircuitCondition`, `EmittedOutputStatement`, `EmittedVariableDeclaration` and `EmittedIssue`. `EmitterMethodOf` types a mirroring method's output as one of the first three, and each Frame setter takes its own kind. At runtime they are plain strings, so nothing checks what a method returns: `Emitter.emitCall` throws only when no Emitter has a method of the call's name. What a Frame composes is a plain `string`.

`_emitTypedChecks`, which returned an object of parts, is gone. `Emitter.buildFrame`, which was `emitBody` and was renamed because it returns a Frame, not text, emits the base check, the short-circuit conditions (`_emitShortCircuitConditions`, still an overridable hook, as ADR-0027 decided) and the post-modifiers' checks (`_emitPostModifierChecks`), and sets each on the Frame. It then lets a composite add its declarations, children's checks and output statements (`_addCompositeParts`), and adds the output's handoff last. `ObjectSchemaEmitter` overrides `_emitPostModifierChecks` to emit only the last `.strict()`, which reads the object's keys rather than its value. The Frame's `addChildSchemaFrameOutputs` is `addChildChecks` again.

> Amended by [ADR-0031](./0031-the-root-schema-compiles-as-a-nested-one-under-one-closing-return.md): the root is compiled as a nested Schema, its checks never return, and `_validate` closes with one `return issues.length > 0 ? { issues } : { value };`. The rest still runs in the base check's `else`.

> Amended by [ADR-0032](./0032-an-emitter-returns-a-schemas-parts-and-the-frame-composes-them-as-a-pure-function.md): `buildFrame` and `_addCompositeParts` are gone, and `ObjectSchemaEmitter` no longer overrides `_emitPostModifierChecks`. One hook, `_emitSchemaParts`, returns a Schema's parts as an object of source text (`SchemaParts`), which a composite's Emitter overrides to add its `composite` parts, and the Frame composes them as a pure function.

> Amended by [ADR-0033](./0033-an-emitter-dispatches-chained-methods-through-typed-method-tables.md): `Emitter.emitCall` is gone. A method's text is typed by the table it is dispatched from, so nothing is cast back to its brand. Each brand is made by one function where its text is written (`emitCheck` and its siblings), and a composite's blank lines are the Frame's formatting, not an empty `EmittedVariableDeclaration`.

## Considered options

- **The base check as its condition and its Issue, two strings from two hooks.** Rejected: it keeps the emitted root as it was, but every schema's Emitter would override two hooks for one check, and the Frame would hold the base check apart from every other check.
- **The base check as one statement, followed at the root by `if (issues.length > 0) { return { issues }; }`.** Rejected: TypeScript narrows the value only inside the check's `else`, so the root's later checks (`value.length`) failed the strict typecheck of the emitted code. It also cost a comparison on every call.
- **Every `emit*` method returns a single string.** Rejected: `''` would mean both "nothing" and the blank line a composite's declarations set its fields apart with. A list says "nothing" with `[]`.
- **`_emitTypedChecks` split into one `_emit…` hook per part.** Rejected: an object names its fields from `Scope` once, and its declarations, children and output all read them, so a split would name them twice.
- **Plain `string` everywhere, with no brands.** Rejected: a short-circuit condition could then be passed where a statement belongs, and nothing would catch it.
