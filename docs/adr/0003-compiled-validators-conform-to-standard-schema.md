# Compiled validators conform to StandardSchemaV1

A `Compiled Validator` produced by `packages/schema-compiler` exposes its own conformant `"~standard"` property, making it a drop-in replacement for the `StandardSchemaV1` schema it was compiled from. This was left open in [ADR-0001](./0001-adopt-standard-schema.md) and is now settled: without it, compiling a schema would silently break any consumer that only knows how to accept a Standard Schema (form libraries, API frameworks), undermining the reason `@pvl/schema` adopted Standard Schema in the first place. The `"~standard".validate` implementation is still the fast, non-tree-walking `Instruction` sequence underneath — conformance adds a thin wrapper, not a performance cost. It reports `vendor: "@pvl/schema"`, not `"@pvl/schema-compiler"` — see [`docs/specification/standard-schema.md`](../specification/standard-schema.md) for the full conformance rules.
