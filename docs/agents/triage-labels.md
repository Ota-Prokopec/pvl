# Triage labels

The skills speak of five triage roles. In this repo's tracker each label is spelled exactly like its role, so apply the role's name as the label.

| Label              | Meaning                                                 |
| ------------------ | ------------------------------------------------------- |
| `needs-triage`     | Maintainer needs to evaluate this issue                 |
| `needs-info`       | Waiting on reporter for more information                |
| `ready-for-agent`  | Fully specified, ready for an AFK agent                 |
| `ready-for-human`  | Requires human implementation                           |
| `wontfix`          | Will not be actioned                                    |
| `bug`              | Something is broken                                     |
| `enhancement`      | New feature or improvement                              |
| `documentation`    | Improvements or additions to documentation              |
| `dont-merge-now`   | Valid PR, but should not be merged yet                  |
| `duplicate`        | Issue or PR already exists                              |
| `good first issue` | Good for newcomers                                      |
| `help wanted`      | Extra attention is needed                               |
| `invalid`          | Issue or PR is invalid                                  |
| `not-grilled-yet`  | Issue has not gone through the grilling process         |
| `question`         | Further information is requested                        |
| `spec`             | Parent spec issue, broken into tickets by `/to-tickets` |
| `ticket`           | Child ticket of a spec, from `/to-tickets`              |
